## Selected projects

### [3D Graphing Calculator](https://github.com/BigGooseNamedBruce/3D-Graphing-Calculator)

A real-time C++ and Vulkan renderer for surfaces defined by `height = f(x, y, t)`. Edit an expression while the app runs, animate it over time, and fly around the result.

- Hand-written expression parser that compiles input into a flat postfix program.
- Geometrically spaced mesh cells that extend the visible domain, with filtered heights and normals to reduce distant shimmer.
- Parallel mesh sampling, background generation, and rebuild skipping for stationary, static surfaces.
- Multisample antialiasing, distance fog, and a procedural grid that adapts to viewing distance.

**C++ · Vulkan · GLSL**

### [Connect Four AI Solver](https://github.com/BigGooseNamedBruce/Connect-Four-AI-Solver)

A full-stack Connect Four game with a Java solver, a Spring Boot API, and a React interface.

- Bitboard representation, negamax search, alpha-beta pruning, and a transposition table.
- An opening book to reduce early-game search work.
- Play against the AI with adjustable difficulty, or against another person.
- Correctness tests and JMH benchmarks across opening, midgame, and endgame positions.

**Java · Spring Boot · React · Python**
